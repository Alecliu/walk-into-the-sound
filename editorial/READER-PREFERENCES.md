# 讀者愛心與推薦

2026-10-03 啟用第一版。列表與文章頁都有愛心；新增喜歡時打開三篇推薦，首頁也依偏好顯示接著讀的文章。取消愛心不再彈窗。按過愛心的文章不重複推薦；盡量分散主要音樂人。同主題或同音樂人的理由會寫出來，沒有配對的文章標示「換個主題，試讀這一篇」。

「偏好與收藏」可選八種主題、輸入音樂人、查看收藏、關閉推薦或清除全部偏好。音樂人用完整名稱比對（正規化大小寫與全半形），不憑部分文字推論身份；不同拼法沒有建立別名時，可能只顯示試讀文章。

只讀寫本站自有的 localStorage 鍵 `walk-into-the-sound:reader:v1`，最多保留 200 篇愛心、30 位音樂人。沒有帳號、伺服器收藏、閱讀追蹤或 YouTube OAuth；不掃描其他儲存鍵。不同瀏覽器與裝置不會同步。儲存遭停用時保留本次頁面狀態並顯示提示。清除只移除這一個鍵。

React 與 scoped CSS 在 `src/content/dashboard/ReaderRecommendations.jsx`、`reader.css`；排序與輸入處理在 `reader-model.js`。推薦以既有 cityStories reviewed rows 呈現，使用公開 DataComponent 與 Dialog，保留原本資料來源入口、焦點管理與網站殼層。

改動後執行 `npm test`、Python 測試及完整建置。瀏覽器要試文章／列表按愛心、推薦跳轉、重整保存、主題與音樂人、取消／清除、關閉推薦，以及窄螢幕彈窗與照片署名。發布仍更新完整 `site/`，不是只推 React 原始碼。
